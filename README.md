## Publicar con GitHub Pages
1. Crear un repositorio nuevo, por ejemplo `katharos-site`.
2. Subir todos los archivos manteniendo la estructura de carpetas.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar la rama `main` y carpeta `/ (root)`.
6. Guardar.
7. GitHub mostrará la URL pública del sitio cuando el despliegue esté disponible.

No es necesario usar frameworks ni instalar dependencias.
