Guía de instalación y uso

Para usuarios no técnicos

1. Antes de comenzar

  • Usa un equipo con Windows.
  • Descarga Katharos únicamente desde el canal oficial.
  • Verifica que tienes autorización para eliminar la información.
  • Conserva una copia de seguridad si necesitas mantener algún archivo.

2. Descargar Katharos

Usa el botón de descarga oficial de la landing. Mientras el release no esté publicado, el enlace permanecerá como placeholder.

3. Verificar la descarga

Cuando el equipo publique un SHA-256 oficial, compáralo con el hash del archivo descargado.

4. Instalar o iniciar

[CONFIRMAR CON EL EQUIPO TÉCNICO SI LA BETA USARÁ INSTALADOR O VERSIÓN PORTABLE]

5. Abrir Katharos

Abre la aplicación y lee las instrucciones y advertencias mostradas en pantalla.

6. Seleccionar archivo o carpeta

Elige únicamente el elemento que realmente deseas eliminar y revisa nombre y ubicación antes de continuar.

7. Revisar

Comprueba los elementos seleccionados y las advertencias presentadas.

8. Confirmar autorización

Declara que eres propietario de la información o que cuentas con autorización para eliminarla.

9. Ejecutar

Inicia el procedimiento y evita cerrar Katharos mientras la operación se encuentra en curso.

10. Consultar el resultado

Revisa si la operación finalizó correctamente, si hubo advertencias, errores o si se generó un reporte.

11. SSD y copias externas

Consulta el Aviso de limitación para conocer las restricciones relacionadas con SSD, backups y almacenamiento en la nube.
